Workspace Tints

A quiet colour code for every Workspace, a sidebar that reads as a tree, and a green row the moment a chat finishes while you are away. Twelve tinted whites, one green — and green only ever means “read me”.

dsh plugin --profile web add dsh-workspace-tints
